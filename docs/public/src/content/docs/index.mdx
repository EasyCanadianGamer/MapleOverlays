## What is MapleOverlays?

MapleOverlays connects your Twitch channel to a set of live overlays and a multi-tenant chat bot. Once invited, the bot joins your channel and responds to commands in chat. Overlays display real-time data (like now-playing track info) as transparent browser sources inside OBS or Streamlabs.
